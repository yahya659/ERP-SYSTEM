# نظام إدارة الحسابات والمخازن - ERP

نظام متكامل لإدارة المخازن والحسابات تم بناءه كاملا باستخدام:

- Laravel
- Blade Template
- MySQL
- Bootstrap

## فكرة المشروع

نظام لإدارة عمليات المخازن والحسابات يساعد المؤسسات والمحلات على تنظيم المخزون، الأصناف، الموردين، العملاء، والفواتير.

## مميزات النظام

### إدارة المخازن
- إضافة وإدارة المخازن
- ضبط بيانات المخزن
- متابعة أرصدة الأصناف داخل المخازن
- إدارة الخزن والصلاحيات

### إدارة الأصناف
- إضافة الأصناف
- تصنيف الأصناف
- ربط الأصناف بالوحدات
- تحديد وحدات البيع والشراء

### إدارة الوحدات

يدعم النظام أنواع الوحدات مثل:

- وحدة جملة
- وحدة تجزئة
- إمكانية إضافة وحدات جديدة

مثال:

كرتون = وحدة جملة  
حبة = وحدة تجزئة


### إدارة الموردين

- إضافة الموردين
- متابعة حسابات الموردين
- تسجيل المشتريات
- متابعة الدفعات والمستحقات


### إدارة العملاء

- إضافة العملاء
- إدارة حسابات العملاء
- متابعة المبيعات
- تسجيل الدفعات


### الفواتير

يدعم النظام:

- فواتير شراء
- فواتير بيع
- تفاصيل الأصناف داخل الفاتورة
- حساب الإجمالي والمدفوع والمتبقي
